HOW PACT WORKS

What is operational today

Persistent LangGraph checkpoints, isolated tenant access, revision-bound approvals, three chunking strategies, BM25 retrieval, real Ollama or OpenAI-compatible inference, a durable job queue, renewal task updates and tracked-change Word exports.

Evaluation boundaries

The example is synthetic. CUAD, ACORD and ContractNLI are component datasets, not evidence that this complete workflow is accurate. Model and dataset provenance, benchmark scripts, and deployment limitations are documented in the repository.

Model profile

Extracted liability, assignment and confidentiality clauses remain reviewer evidence. Automatic policy decisions currently cover renewal notice periods only.
